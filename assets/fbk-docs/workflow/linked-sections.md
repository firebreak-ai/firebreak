Use when writing a linked section: Commitments in `prd.md`, Design choices in a design file, or Requirements in `spec.md`. Firebreak reads a small part of Markdown in these documents and refuses the rest, naming the file, the line and, inside the section, the item.

Inside the section, including its heading, write only these line shapes, each starting at the beginning of the line: blank lines; headings with `#`; paragraph lines; quote lines, each `>` alone or `>`, a space and plain text, ended by a bare `>`, a blank line, a heading or a list item; fenced code blocks; and list items (`-`, `*`, `+` or a number such as `1.`, one space, then plain text). Only a nested list item or a plain-text continuation line may be indented, with spaces, to exactly where its parent item's text starts. Right after paragraph or quote text, a numbered list starts at `1.`; leave a blank line before one that starts elsewhere. Leading tabs, other indentation, horizontal rules and lines of `-` or `=` under text are refused. Anywhere in the document, keep links out of headings, write no reference-link definitions (`[label]: destination`), and start each fenced block at the beginning of a line, outside lists and quotes. Write item names in plain text with no emphasis, backticks, brackets, or underscore at the start or end of a word, and each link as `[name](path#anchor)` on one line with no title. Use no HTML or comments; put anything in angle brackets, or a `<` directly before a letter (such as `Vec<u8>`), in inline code. Open and close inline code on the same line, and escape a bracket meant as text; inside an item, put literal backticks in inline code or a fenced block rather than escaping them. Images do not count as links, and headings and links inside fenced blocks, inline code and quotes do not count.

An anchor is the heading in lowercase, with punctuation dropped and spaces turned into hyphens. Links elsewhere in the document, and links to code or other documents, are free. Renaming a linked heading breaks its links, and the next downstream close names them.
