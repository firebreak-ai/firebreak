# Intent review

The runtime sends this file's Decision, Check and Later deliverables sections to the intent reviewer. Keep each item on one line.

## Decision

Can this intended behavior and scope guide the next design or specification phase?

## Check

- Check the human problem, desired observable behavior, scope boundaries, acceptance examples, and consequential open decisions.
- Assess internal consistency and feasibility at the level of the intended capability; use independently attributed human decisions when provided.

## Later deliverables

- design
- specification
- task breakdown
- implementation
- executable tests
- delivery documentation
