# Implementation review

The runtime sends this file's Decision, Check and Later deliverables sections to the implementation reviewer. Keep each item on one line.

## Decision

Does the delivered behavior satisfy accepted contracts with meaningful executable verification and maintainable code?

## Check

- Trace observable requirements and failure cases to delivered code, tests, and declared documentation.
- Check that plausible wrong behavior would fail the actual tests; passing assertions and coverage alone do not prove correctness.
- Inspect maintainability, duplication, dependency direction, regression risks, and fidelity to requirements.
