The existing code-review guide now defines independent verification of material fixes and their regression tests, a bounded remediator assignment, evidence-backed treatment of interacting safeguards, and follow-up review of affected behavior and related paths. The existing consistency audit accounts for same-defect siblings within accepted scope; the shared test-integrity audit rejects both vacuous coverage and unsupported claims that a useful test cannot fail. These extend existing guidance rather than introducing another lens or execution engine.
